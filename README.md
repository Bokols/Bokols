### 🚀 Proyectos destacados

#### [Aplicación de Pronóstico de Demanda](https://github.com/Bokols/Product-Demand-Forecasting-Application)
> Modelo LightGBM para predicción de demanda retail con app web Streamlit
- Logró MAE de 7.3 unidades/día
- Redujo faltantes de stock en 30K USD/mes

#### [Seguros Sure Tomorrow](https://github.com/Bokols/sure-tomorrow)
> Segmentación de clientes y predicción de riesgo con cifrado de datos
- Implementó clustering K-Means para grupos de clientes
- Desarrolló modelo de predicción de beneficios

#### [Predicción de Precios de Autos Usados](https://github.com/Bokols/Prediccion_y_Exploracion_de_Precios_de_Automiviles_con_Streamlit)
> App bilingüe Streamlit para estimación de precios
- RMSE de $1,591 en 350K+ registros
- Análisis de importancia de características

#### [Predicción de Fuga de Clientes](https://github.com/Bokols)
> Modelo Random Forest para churn en telecomunicaciones (86% AUC-ROC)
- Balanceó precisión (91%) y recall (74%)
- Estrategias proactivas de retención
